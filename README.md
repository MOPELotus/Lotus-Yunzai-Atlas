# Lotus-Yunzai 图鉴

读取原神、星铁和绝区零的本地图鉴快照。设置 `LOTUS_ATLAS_DATA_DIR` 指向含 `map.json` 和 `items/` 的数据目录，再在宿主发送 `#角色图鉴 原神 神里绫华`。发送 `#图鉴状态` 可查看角色分类的版本与收录数量。

首次部署没有图鉴数据时，可按[公网首装](docs/legacy-source-layout.md#从公网准备首版)从原公开来源准备三款游戏的固定快照。机器人启动时直接读取本地快照。

数据目录默认是主仓的 `data/atlas/data`，已发布的 `data/atlas/current` 优先。两者都不存在时，可以只读使用原插件目录中的现有导出。两份来源不同则通过 `LOTUS_ATLAS_DATA_DIR` 指定。需要迁入新快照管理时，见[旧导出初始化](docs/legacy-source-layout.md#初始化已有旧导出)。

主人可用 `#检查图鉴更新` 和 `#更新图鉴` 查看并更新已支持的分类。维护命令核对正式发布版本，正式来源落后时保留现用快照。 原神、星铁和绝区零成就也在维护范围内。成就更新按原分类索引取数，原神沿用原分类图。缺少已有分类或任一已有成就时保留现用快照。绝区零另外核对原一级分类、子分类和互斥表。

绝区零等级以同版本角色详情为准。对于旧导出的等级字段，按官方发布的安比和耀嘉音样例核对 A/S 级。详情缺失或版本不符时会标为待核对。[官方调频说明](https://zenless.hoyoverse.com/zh-cn/news/129524)

装备查询可用 `#武器图鉴 原神 西风剑`、`#光锥图鉴 锋镝` 或 `#音擎图鉴 深海访客`。也可用旧版的 `#西风剑`、`*锋镝`、`%深海访客` 直查。名称和 ID 来自对应分类的索引，适用范围来自同版本详情。

套装与邦布可用 `#圣遗物图鉴 冰风迷途的勇士`、`#遗器图鉴 太空封印站`、`#驱动盘图鉴 啄木鸟电音`、`#邦布图鉴 企鹅布`。也可通过 `#套装图鉴` 跨游戏查套装。

使用 `#成就图鉴` 按名称或 ID 查找成就，使用 `#成就分类 原神 天地万象 第2页` 浏览分类。分类和条件以本地快照为准。

使用 `#挑战图鉴 原神 深境螺旋` 查看记录，再用名称或 ID 查看关卡资料。例如 `#挑战图鉴 星铁 异相仲裁 1`。起止时间按快照字段显示，导出时间只作资料参考。
